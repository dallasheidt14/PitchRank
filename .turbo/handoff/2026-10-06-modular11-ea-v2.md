## Key facts the plan rests on

- **An EA team id is an age slot, not a squad.** The same uid is used every season (verified for
  7155, 7343 and 3432), so links must be keyed as `<uid>:<season>`.
- **Importer gotcha:** `stream_games_csv`/`load_games_csv` wrap id and score conversion in one
  `try`, so a non-numeric id leaves the scores as strings. Plan Task 2 fixes this.
- **The `are_same_club` trap:** it accepts club branches (Santa Ana ↔ Santa Monica, TFA OC ↔
  SGV). Never auto-pick among "duplicate" candidates without the branch check; the Santa Ana
  mistake came from exactly that.
- **Hand-back bug (minor):** `handback.csv` loses created-team ids on re-runs, so read created
  teams from `teams` where `provider_id` is `modular11_ea`.
- **Paging:** Modular11 pages are 1-indexed and `open_page=0` aliases page 1. The existing MLS
  NEXT spider likely skips each age's last page. This is unlogged, and the owner has not yet been
  asked about logging it.
